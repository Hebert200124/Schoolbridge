File Format

The first row must be a header. Required columns:

  • first_name - student first name
  • last_name - student last name
  • form - e.g. "Form 1" (a plain number like 2 is converted)

Optional columns:

  • curriculum - ZIMSEC or CAMBRIDGE (defaults to ZIMSEC)
  • email, phone

Student IDs and registration numbers are generated automatically. Each student is created with default password student123 and a fee account for the current term. Rows missing required fields are skipped.
